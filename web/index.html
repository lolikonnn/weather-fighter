本站不是气象局开的哦！说白了就是个给天气预报套了层炒股软件皮的 套皮小玩具，数据都是搬来的 (๑•́ ₃ •̀๑)

✧ 数据都是从这些地方搬的
  • 中国气象局 / 中央气象台 —— 实况、预报、逐 3 小时、雷达拼图、卫星云图、 台风路径、预警信号
  • 中国天气网 —— 城市代码、15/40 日预报、天气日历、历史同期
  • Open-Meteo（国外的免费源）—— 逐小时、历史日K、空气质量、气溶胶、近十年气候
  • NOAA SWPC（美国）—— 极光要用的 Kp 指数、太阳风、耀斑、太阳黑子
  • NASA GIBS（美国）—— 海表温度与海温距平（「🌡 海陆温」里的海洋那一档）
  • USGS · 中国地震台网 · 日本气象厅 —— 「🌋 地震」的目录与地震预警
  • David Lorenz 的光污染地图集 —— 观星页那个「本站光污染」等级
  • 阿里 DataV —— 行政区划底图（随页面一起下载，不联网查）

传播的时候也照规矩来：数据来源、气象台站号和发布时刻都摆在该摆的地方。 本站不发布任何自制的天气预报 (｡･ω･｡)

✧ 哪些是本站自己算的 / 自己编的
  • 天文那一整套都是本地算的：日出日落、月出月落、月相、太阳与月亮此刻的高度方位、 日地距离、黄金与蓝调时刻、亮星与行星方位、流星雨日历。 它们是推算的近似值，跟紫金山天文台那种权威结果可能差几分钟到十几分钟。
  • 观星页那个评分是本站自定的口径（云多少、月亮多亮、通透度如何，各占几分）， 不是任何机构的标准。
  • 光污染那个等级是 1～9 级，数值越小越暗（1 级是最黑的荒野，9 级是市中心）。 它来自第三方地图集，算的是"天顶有多亮"的模拟值 —— 它不是波特尔（Bortle）等级：底图作者明确说过不希望两者混用。 观星页会顺手告诉你这个级别够不够看银河（一般要 5 级以下）✧
  • 朝霞 / 晚霞 / 火烧云是本站自拟的启发式，不是权威预报， 也没有哪个机构在公开做这件事。它只看中高云够不够当"画布"、低云会不会把地平线挡死、 气溶胶够不够浓；远处的地形、云的具体形状、飞机拉线它都看不见。 数据不够的时候它会直接显示"数据不足"，不硬凑一个分数。
  • 观星页那张「全年气候」是近似值：拿近 10 年的全天平均云量算的。 它看不见夜里那一段，所以会低估真正的晴夜数（白天有云、夜里放晴的日子会被算掉）。 它适合用来比较"哪个月更值得来"。
  • Open-Meteo 额度用尽的时候，那条气温曲线是插出来的：拿气象局发布的逐 3 小时值 做平滑连线画出来的，不是官方逐时预报，只是示意。 图上和光标里都分了颜色 —— 哪个点是官方原值、哪个点是插值，一眼看得出来 ✧
✧ 几件容易误会的事
  • 屏幕上可能显示的是缓存：为了打开快，会先把上次看到的那份直接摆出来， 再去拉最新的 —— 底部状态栏会写清数据是哪时候的。
  • 你没点的时候，它也在替你取数：收藏的城市会被悄悄预取好（最多 12 座）， 这样切过去不用等。省流模式、或者网络很差的时候不会这么做 ✧
  • 地震的震级和震中会被官方修订，这里显示的是最后一次拿到的那份； 「地震预警」那几条是各机构的最近一次发布，不代表此刻正在发生 —— 界面上写了"多久之前"，只有 30 分钟以内的才按告警显示 ✧
  • 预警信号是搬运原文，红橙黄蓝的排序是本站排的；是否生效、什么时候解除， 以官方发布为准。
  • 台风那条虚线是官方预报、实线是已经走过的路；强度可能比实际慢半拍。
  • 海表温度是卫星融合产品，有几天延迟；陆地那一档是实况图。
  • 定位只在你点的时候才请求：坐标只存在你自己的浏览器里，本站不收集、不上传 ✧
  • 「点击做空天气」是个游戏：跟钱没关系，不是投资建议，更不是预报； 存档也只在你本机 ✧
  • 安装包是本机自己签名的（不是从应用商店下的），装的时候系统会提醒"来源不明"； 它也不会自动更新，想升级得回来重新下载 ✧
✧ 你的数据

本站是个纯静态页面 —— 没有账号、没有后端、不埋点、不统计。 收藏的城市、定位结果、游戏存档、各种缓存，全都只存在你自己的浏览器里， 换台设备就没了，我们这边一条都看不到 ✧

这些炒股词，用天气话讲

图表上的词

分时
今天的每小时气温，连成一条线。和股票分时图一模一样。
7日
昨天 + 今天 + 未来五天，连起来的每小时气温，方便看几天里的冷热节奏。
蜡烛 / K 线
一根蜡烛就是一天。粗柱子的上下两端＝当天 0 点和 23 点的气温（0 点高就是红色，0 点低就是绿色）；细线（影线）的两端＝当天最高和最低气温。
日K / 周K / 月K
一天一根蜡烛 / 一周一根 / 一个月一根。周期越长，噪音越少、趋势越清楚。
预报K
未来 15 天的预报气温，用同样的蜡烛画法，所以是"还没发生的K线"。
均线 MA5 / MA10 / MA20 / MA60
最近 5 / 10 / 20 / 60 天的平均气温连成线，用来看大方向。数字越大越平滑。
温差
下面那排柱子的默认口径：高度＝当天温差（最高减最低），柱子越高说明那天忽冷忽热。
降水 / 风 / 云量 / 空气
同一排柱子的另外四种口径，也都是未来两天的逐小时预报。
降水概率
那一小时下雨的可能性（百分比）。柱子＝雨量毫米，黄线＝概率。两者不是一回事：概率高不一定雨大。
阵风 / 风向
阵风＝短时最大风速（紫色虚线）。箭头指风吹去的方向 —— 气象上的"西南风"指风从西南吹来，所以箭头指向东北。
云量
天空被云遮住的百分比。低云／中云／高云分开画，白线是总云量。云越厚越可能阴天。
空气质量 AQI
越小越好：≤50 优、≤100 良、≤150 轻度污染、≤200 中度污染、≤300 重度污染、再高是严重污染。虚线 100 就是"良"的分界。

主图上的几条线

红色实线（带红色渐变面积）
当天的气温曲线，就是这只"股票"的价格本身。分时图上一点＝一个小时；日K／周K／月K 上一点＝一根蜡烛的收盘价。红色只是用了炒股软件里"涨"的颜色，不代表气温正在升。
金色线
均温线：最近若干个点的平均气温（分时图是当天均线，K 线图上是 MA5 / MA10 / MA20）。鼠标停在主图上，小窗里那一行也叫「均温」。它比气温线平滑，用来看大方向 —— 气温线在均温线上方，说明最近在变暖。
灰色水平虚线
基准线，值＝昨天 23 点的气温。所有涨跌幅都是跟它比出来的：气温线在它上面就是升温，在下面就是降温。
深浅交替的竖条背景
日界带：一明一暗代表一天过去了，分界处那根竖虚线就是 0 点。7日／多日分时图靠它数"这是第几天"。
蓝／绿／灰蓝／紫 的细线
这条是你自己叠上去的：在下方副图（温差／降水／风／云量／空气）那一排右边点「📈 叠到主图」，就能把那个口径的曲线拉到主图对照着看。颜色对应：降水＝蓝、风速＝绿、云量＝灰蓝、PM2.5＝紫。不点就没有这条线。
K 线图上的 MA5 / MA10 / MA20 / MA30 / MA60
只有 K 线视图（日K／周K／月K／预报K）才有的均线，就是最近 5／10／20／30／60 根蜡烛的收盘平均，颜色依次是白 / 黄 / 紫 / 绿 / 蓝。周期越长越平滑：几条贴在一起说明没有明显趋势，散开发散说明趋势正在走出来。

右侧和顶部的词

未来 5 天高低温
就是未来 5 天的最高温和最低温。上半部分从下往上是第 1～5 天的最高温，下半部分从上往下是第 1～5 天的最低温。
每小时气温流水
最近每个整点的气温和降水量，最新的在最上面。
今日 0 点 / 昨日 23 点
就是字面意思：今天 0 点的气温、昨天 23 点的气温。用来看这一整天是升了还是降了。
全天波动
今天最高气温减最低气温，数字越大说明这天忽冷忽热得越厉害。
同期
往年今天的历史平均最高／最低气温，用来比较"今年是偏热还是偏冷"。
+2.3 / +13.3%
和昨天同一时刻相比，气温差了 2.3℃，涨幅 13.3%（涨跌幅＝差值 ÷ 昨日同时刻气温）。
天气指数
顶部那排：把几个代表城市当成"大盘指数"，一眼看清全国在升温还是降温。
红色 / 绿色
红色＝比昨天高（升温），绿色＝比昨天低（降温）。顶栏可以改成国外习惯的反过来。
